# 클린하우스 입주청소 — Creative Build Brief / 제작설계서 준비

상태: CREATIVE BRIEF CONFIRMED
현재 단계: 최종 제작설계서 작성 전
Page Architecture: MULTI PAGE
Selected Design: B / Editorial Trust
Secondary Influence: C / Result First의 Before / After 결과 강조 방식

이 파일은 선택된 디자인 방향을 전체 멀티페이지 경험으로 확장하기 위한 Creative Build Brief다.
다음 단계에서 이 내용을 기술·컴포넌트 수준의 최종 제작설계서로 구체화한다.

## 1. Project Experience
클린하우스 사이트는 하나의 긴 랜딩페이지가 아니라, 사용자가 자신의 질문에 맞는 페이지로 빠르게 이동하고 필요한 정보만 확인한 뒤 견적을 요청할 수 있는 멀티페이지 전환형 사이트다.

방문자는 다음 질문 중 하나를 가지고 들어온다.
- 얼마인가?
- 추가비가 생기는가?
- 어디까지 청소하는가?
- 실제로 잘하는가?
- 문제가 생기면 어떻게 되는가?

사이트는 모든 내용을 한 번에 설명하지 않고, 질문별로 가장 적합한 페이지에서 답을 제공한다.

최종 감정은 다음과 같아야 한다.
“가격과 범위를 이해했고, 결과와 보완 방식도 확인했으니 견적을 받아봐도 되겠다.”

## 2. Conversion Goal
Primary Conversion:
- 견적 요청

Secondary Actions:
- 전화 상담
- 카카오톡 상담

Primary CTA는 주요 화면/섹션당 최대 1개를 유지한다.
전화·카카오톡은 동일 위계의 큰 버튼으로 Primary CTA와 경쟁시키지 않는다.

## 3. Global Design Language
전체 사이트는 B / Editorial Trust를 기본으로 한다.

핵심 언어:
- 큰 타이포그래피
- 비대칭 편집형 구성
- 이미지와 텍스트의 긴장감 있는 배치
- 가격·실적 숫자의 강한 시각적 앵커
- 밝은 영역과 다크 영역의 명도 전환
- 카드 반복 대신 페이지 목적에 맞는 레이아웃 변화

C / Result First의 영향은 Cases / Reviews와 Before / After에 집중한다.
사이트 전체를 다크톤이나 이미지 오버레이 중심으로 만들지 않는다.

## 4. Home Direction
역할:
- 전체 내용을 모두 설명하는 페이지가 아니라 빠른 판단과 탐색의 허브

Hero:
- B의 비대칭 Editorial Hero 적용
- 큰 한국어 타이포그래피와 주거공간 이미지의 교차 구성
- 일반적인 50:50 분할 Hero 금지
- 첫 화면에서 청결감과 브랜드 인상을 동시에 제공

Hero Message:
- 새집의 시작을 더 깨끗하고 편안하게

Primary CTA:
- 청소 견적 요청하기

Home Flow:
Hero
→ 대표 가격
→ 추가비 사전 안내
→ 서비스 범위 요약
→ 1,200건+ 신뢰 장면
→ 대표 Before / After
→ 검수·보완 요약
→ 후기 요약
→ Final CTA

Home에서는 Price, Service, Cases, Guide의 상세 내용을 반복하지 않는다.
각 요약 구간은 해당 상세 페이지로 자연스럽게 연결한다.

## 5. Service Direction
주요 질문:
- 어디까지 청소해주는가?

역할:
- 서비스 범위와 공간별 청소 내용을 직관적으로 이해시키는 페이지

시각 방향:
- 큰 공간 이미지 + 편집형 텍스트 배치
- 주방, 욕실, 창틀, 바닥, 수납공간을 작은 아이콘 카드로 반복하지 않는다.
- 이미지가 서비스 범위를 이해시키는 역할을 해야 한다.
- 스크롤하면서 실제 집 안의 공간을 이동하는 듯한 리듬을 만든다.

정보:
- 입주청소
- 이사청소
- 공간별 범위
- 냉장고 / 세탁기 / 오븐 / 전자레인지 옵션
- 작업 방식

## 6. Price Direction
주요 질문:
- 얼마인가?
- 추가비가 언제 생기는가?

역할:
- 사이트에서 가장 정보 밀도가 높지만 가장 빠르게 읽혀야 하는 페이지

시각 방향:
- 대표 가격 180,000원을 큰 타이포그래피로 먼저 제시
- 나머지 가격은 명확한 인덱스/리스트 또는 정제된 표 구조
- 작은 가격 카드 반복 금지
- Editorial 감도보다 가격 탐색성과 비교 가독성을 우선

고정 가격:
- 20평 이하 180,000원
- 21~30평 230,000원
- 31~40평 280,000원
- 41~50평 330,000원
- 51평 이상 상담

옵션:
- 냉장고 30,000원
- 세탁기 30,000원
- 오븐 20,000원
- 전자레인지 20,000원

추가비 가능 조건:
- 베란다·창틀 심오염
- 반려동물 털
- 심한 생활오염
- 폐기물 처리

핵심 메시지:
- 추가 비용이 필요한 경우 작업 전에 안내합니다.

## 7. Cases / Reviews Direction
주요 질문:
- 실제로 잘하는가?

이 페이지는 C / Result First의 영향을 가장 강하게 적용한다.

Before / After:
- 작은 갤러리 카드보다 큰 이미지 중심
- near full-width 또는 큰 비대칭 비교 허용
- overlap, offset, staggered image 사용 가능
- 결과가 설명보다 먼저 인지되어야 함

Trust:
- 1,200+를 작은 통계 카드가 아니라 강한 Proof 장면으로 사용
- 가능하면 실제 작업 이미지와 결합

Reviews:
- SaaS식 별점 카드보다 실제 카카오톡/문자 대화를 읽는 듯한 레이아웃
- 실제 공개 시 비식별 처리된 실제 자료로 교체

## 8. Guide / FAQ Direction
주요 질문:
- 어떻게 진행되는가?
- 문제가 생기면 어떻게 되는가?

실제 과정:
상담 및 예약
→ 현장 정보 확인
→ 견적
→ 방문 청소
→ 고객 검수
→ 미흡 부분 보완

시각 방향:
- 6개의 동일 카드 금지
- timeline, connected narrative, scroll progression 우선
- 정책 설명은 긴 박스보다 편집형 타이포와 구조적 구분을 사용

정책 FACT:
- 작업 완료 후 현장 검수
- 미흡 시 사진 접수 후 보완 방문 여부와 일정 협의
- 예약 변경 최소 2일 전
- 서울·경기 중심, 세부 방문 가능 여부 상담 확인

## 9. Estimate Direction
역할:
- 결정한 사용자가 방해받지 않고 견적을 요청하는 전환 전용 페이지

시각 방향:
- 가장 단순하고 집중된 페이지
- 긴 브랜드 설명, 반복된 Proof, 과도한 이미지 금지
- B의 타이포그래피와 브랜드 언어만 최소한으로 유지
- 폼과 다음 행동이 중심

보조 정보:
- 추가비 필요 시 사전 안내
- 서울·경기 중심
- 일정 상담 후 확인

## 10. Visual Rhythm
페이지마다 동일한 템플릿을 복제하지 않는다.

Home:
- 밝은 Editorial Hero
- 정보 밀도가 높은 가격 요약
- 다크 Trust 장면
- 강한 결과 이미지

Service:
- 밝고 이미지 중심
- 공간별 시각 리듬

Price:
- 정제된 정보 디자인
- 큰 숫자와 명확한 리스트

Cases / Reviews:
- 이미지 비중 최고
- 밝음/어두움 대비 강함
- 결과 중심

Guide / FAQ:
- 연결감 있는 프로세스
- 차분한 정보 리듬

Estimate:
- 가장 단순하고 집중된 화면

## 11. Motion Direction
Motion Intensity:
- Light / Premium Accent

허용:
- image reveal
- text reveal
- subtle depth movement
- 숫자 강조 transition
- Before / After interaction
- process progression

금지:
- scroll hijacking
- 의미 없는 반복 parallax
- 콘텐츠보다 먼저 보이는 animation

## 12. FACT / MOCK Boundary
확정 FACT는 변경하지 않는다.

고정:
- 서비스
- 가격
- 옵션 가격
- 추가비 조건
- 운영 지역
- 1,200건+ 실적
- 검수·보완 정책
- 실제 프로세스

DESIGN MOCK ASSET 허용:
- Hero Image
- Service Image
- Before / After
- Mock Review
- Sample Name

Mock Asset은 실제 고객 사례라고 주장하지 않는다.
실제 공개 전 실제 자료로 교체한다.

## 13. Success Condition
사용자가 사이트 전체를 모두 읽지 않아도 Price, Service, Cases, Guide 중 자신의 질문에 맞는 페이지를 확인한 뒤 다음 판단에 도달해야 한다.

“가격도 이해했고, 추가비도 미리 안내받을 수 있으며, 결과와 보완 방식도 확인했으니 견적을 받아봐도 되겠다.”

## 14. 다음 단계
이 Creative Build Brief를 기준으로 최종 제작설계서를 확정한다.

최종 제작설계서에서 추가 확정할 항목:
- 최종 색상 토큰
- 타이포그래피 토큰
- 최대 콘텐츠 폭
- Grid / spacing
- 공통 Header / Footer
- 페이지별 세부 섹션
- 컴포넌트 정의
- 이미지 비율
- CTA 상태
- 데스크톱 / 태블릿 / 모바일 변환 규칙
- 폼 상태와 연결정보
- 접근성
- prefers-reduced-motion
- QA 기준
- 실제 공개 전 교체 항목

최종 제작설계서 확정 전에는 전체 멀티페이지 구현을 완료 처리하지 않는다.
