# 클린하우스 입주청소 — 디자인 방향

상태: DESIGN EXPLORATION
현재 단계: 디자인 시안 비교 중
주의: 아직 최종 선택안이 확정되지 않았다.

## 1. 현재 승인된 디자인 기준
Primary Direction:
STANDARD

Visual Character:
- Clean Service
- Trust-first
- Premium Visual Quality
- Light / Premium Motion Accent

## 2. Visual Concept
“입주 전 마지막 걱정을 지워주는 깨끗한 시작”

## 3. 디자인 목표
- 신뢰감
- 깨끗함
- 친근함
- 위생적인 느낌
- 지나치게 딱딱하지 않음
- 일반적인 저가형 청소업체 템플릿처럼 보이지 않음
- 정보 전달력과 시각적 완성도 균형

## 4. 피해야 할 방향
- 화이트 + 연두색 카드 반복
- SaaS 랜딩페이지 스타일
- 작은 아이콘 카드 반복
- 청소 전단지 느낌
- 모든 섹션이 같은 구조
- Hero가 텍스트 박스 + 버튼 + 작은 사진으로 끝나는 평범한 구성
- 핵심 가격·실적·Before/After를 작은 카드 안에 묻는 방식

## 5. 시안 비교 후보

### A — Clean Premium
- 밝고 정돈됨
- 실제 주거공간 이미지 중심
- 신뢰와 전환 우선
- 프리미엄하지만 부담스럽지 않음

### B — Editorial Premium
- 라이프스타일/인테리어 브랜드 같은 감도
- 이미지와 타이포 중심
- 일반 청소업체 느낌 최소화
- 브랜드 인상 강화

### C — Premium Motion
- Clean Premium 기반
- 스크롤/레이어/이미지 전환 강화
- subtle parallax
- image reveal
- 숫자 animation
- Before/After interaction
- 정보 전달력 유지

## 6. 디자인 시안용 가상 자산 규칙
현재는 실제 구현 전 디자인 방향 검증 단계다.

실제 자료가 없어도 디자인 완성도를 판단하기 위해 시안용 가상 자산을 사용할 수 있다.

허용:
- Hero용 가상 주거공간 이미지
- 가상 청소 작업 장면
- 가상 서비스 이미지
- 가상 Before / After
- 가상 작업사례 이미지
- 후기 레이아웃 검증용 샘플 후기
- 가상 고객명

목적:
- 이미지 비중
- 레이아웃
- 타이포그래피
- 섹션 리듬
- 가격/신뢰/사례 표현 방식
- 전체 비주얼 방향

가상 자산은 실제 클린하우스의 실제 사례라고 간주하지 않는다.

## 7. 시안 평가 기준
1. 첫 화면에서 신뢰가 느껴지는가?
2. 일반 청소업체 템플릿처럼 보이지 않는가?
3. 가격 정보가 쉽게 보이는가?
4. 실제 공간 이미지가 핵심 요소로 작동하는가?
5. Before / After가 충분히 강한가?
6. 1,200건+가 시각적 신뢰요소로 작동하는가?
7. 카드형 반복이 과하지 않은가?
8. 페이지 전체에 명도·밀도·레이아웃 리듬이 있는가?
9. CTA가 명확한가?
10. 실제 웹사이트로 구현 가능한가?
11. 모바일에서도 핵심 디자인이 유지 가능한가?
