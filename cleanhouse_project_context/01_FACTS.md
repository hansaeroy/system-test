# 클린하우스 입주청소 — 확정 사업 사실

상태: CONFIRMED FACT DATA
용도: 고객이 제공한 실제 사업 사실 저장
주의: 이 파일의 사업 사실은 임의 변경·추가하지 않는다.

## 브랜드
- 브랜드명: 클린하우스 입주청소

## 주요 서비스
- 입주청소
- 이사청소

### 입주청소
- 입주 전 빈집 전체 청소

### 이사청소
- 이사 전후 생활오염과 묵은 때 중심 청소

## 기본 청소 범위
- 주방
- 욕실
- 창틀
- 바닥
- 수납장

세부 범위는 실제 서비스 자료가 추가 제공되면 확장한다.

## 옵션 서비스 및 가격
- 냉장고 내부 청소: 30,000원
- 세탁기 내부 청소: 30,000원
- 오븐 내부 청소: 20,000원
- 전자레인지 내부 청소: 20,000원

## 평수별 기본 가격
- 20평 이하: 180,000원
- 21~30평: 230,000원
- 31~40평: 280,000원
- 41~50평: 330,000원
- 51평 이상: 상담 후 안내

## 추가 비용 발생 가능 조건
- 베란다·창틀 오염이 심한 경우
- 반려동물 털이 많은 경우
- 심한 생활오염이 있는 경우
- 폐기물 처리가 필요한 경우

추가 비용이 필요한 경우 작업 전에 사진 확인 또는 상담을 통해 먼저 안내한다.

## 작업 과정
상담 및 예약
→ 현장 정보 확인
→ 견적 안내
→ 방문 청소
→ 고객 검수
→ 미흡 부분 보완

## 운영 지역
- 서울·경기 지역 중심
- 지역별 방문 가능 여부는 상담 시 확인

## 보완 및 예약 정책
- 작업 완료 후 고객 검수
- 청소 미흡이 확인되면 사진 접수 후 보완 방문 여부와 일정 협의
- 예약 변경은 최소 2일 전 요청

현재 미확정이므로 만들지 말 것:
- 보완 요청 가능 기간
- 무료 보완 조건
- 보완 횟수
- 보완 제외 사유

## 서비스 특징
- 전문 장비 사용
- 친환경 세제 사용
- 공간별 체계적인 청소
- 고객 검수 및 미흡 부분 보완

주의:
- 특정 장비 브랜드 임의 생성 금지
- 특정 세제 브랜드·인증·성분 임의 생성 금지

## 신뢰자료
- 누적 1,200건+ 입주·이사청소 진행
- 카카오톡 상담 후기 보유
- 문자 후기 보유
- 후기 개인정보 비식별 처리 후 일부 공개 가능

## 현재 실제 자료/연결정보 상태
아직 실제 제작 자료가 전달되지 않은 항목:
- 실제 Hero/서비스 사진
- 실제 Before / After
- 실제 후기 원본
- 실제 전화번호
- 실제 카카오톡 상담 URL
- 실제 문의폼 endpoint
- 개인정보 처리방침 및 개인정보 수집 동의

이 항목들은 사업 사실 미확정이 아니라 실제 파일/연결값 미제공 상태다.
