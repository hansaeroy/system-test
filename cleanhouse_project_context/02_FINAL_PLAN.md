# 02_FINAL_PLAN.md
# 클린하우스 입주청소 — 최종 기획

상태: FINAL PLAN
Page Architecture: MULTI PAGE
용도: 홈페이지 정보 구조, 전환 흐름, 페이지별 역할, 메시지 우선순위 기준

## 1. 핵심 목표
Primary Conversion:
- 견적 요청

Secondary Actions:
- 전화 상담
- 카카오톡 상담

모든 페이지는 최종적으로 견적 요청으로 연결한다.
전화와 카카오톡은 Primary CTA와 동일 위계로 경쟁시키지 않는다.

## 2. 고객의 핵심 질문
방문자는 사이트 전체를 모두 읽지 않아도 자신의 질문에 맞는 페이지로 바로 이동할 수 있어야 한다.

핵심 질문:
1. 기본 가격은 얼마인가?
2. 추가 비용은 언제 발생하는가?
3. 어디까지 청소하는가?
4. 실제로 잘하는가?
5. 작업 후 미흡하면 어떻게 되는가?
6. 어떻게 진행되는가?
7. 원하는 날짜·지역에 가능한가?

## 3. 핵심 메시지
- 새집의 시작을 더 깨끗하고 편안하게
- 청소 비용, 먼저 확인하세요.
- 추가 비용도 먼저 안내합니다.
- 보이지 않는 곳까지 확인하는 청소
- 작업 완료 후 고객이 직접 확인합니다.

## 4. 전환 UX 원칙
- Don't Make Me Think
- Pain First
- One Message Per Screen
- One Primary Ask Per Screen
- Visualization First

고객 질문 흐름:
문제
→ 즉시 답변
→ 다음 불안
→ 증거
→ 다음 불안
→ 증거
→ 행동

멀티페이지에서는 사용자가 반드시 Home의 모든 섹션을 순서대로 읽게 하지 않는다.
각 페이지가 하나의 주요 질문을 해결하고 Estimate로 연결되는 구조를 우선한다.

## 5. 사이트맵

## 8. 가격 및 정책 FACT
기본 가격:
- 20평 이하: 180,000원
- 21~30평: 230,000원
- 31~40평: 280,000원
- 41~50평: 330,000원
- 51평 이상: 상담

옵션:
- 냉장고 내부: 30,000원
- 세탁기 내부: 30,000원
- 오븐: 20,000원
- 전자레인지: 20,000원

추가 비용 가능 조건:
- 베란다·창틀 심오염
- 반려동물 털
- 심한 생활오염
- 폐기물 처리

원칙:
- 추가 비용이 필요한 경우 작업 전에 안내
- 작업 완료 후 고객 현장 검수
- 미흡한 경우 사진 접수 후 보완 방문 여부와 일정 협의
- 예약 변경 최소 2일 전
- 서울·경기 중심, 세부 방문 가능 여부 상담 확인

## 10. 정보 사용 원칙
- 01_FACTS.md의 사실은 임의 변경 금지
- 가격·정책·실적·서비스 범위를 새로 만들지 않음
- 03_DESIGN_DIRECTION.md에서 확정된 디자인 방향을 따른다.
- 실제 자료가 없는 영역은 디자인 단계에서 DESIGN MOCK ASSET 사용 가능
- 실제 공개 전 실제 자료로 교체
- Home에 모든 상세 콘텐츠를 중복해서 넣지 않는다.
