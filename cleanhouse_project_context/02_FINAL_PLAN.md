# 클린하우스 입주청소 — 최종 기획

상태: FINAL PLAN
용도: 홈페이지 정보 구조, 전환 흐름, 메시지 우선순위 기준

## 1. 핵심 목표
1차 전환:
- 견적 요청

2차 전환:
- 전화 상담
- 카카오톡 상담

## 2. 고객의 핵심 불안
방문자는 다음을 빠르게 확인할 수 있어야 한다.

1. 어디까지 청소하는가?
2. 기본 가격은 얼마인가?
3. 추가 비용은 언제 발생하는가?
4. 실제로 꼼꼼하게 하는가?
5. 작업 후 미흡하면 어떻게 되는가?
6. 원하는 날짜·지역에 가능한가?

## 3. 핵심 메시지
- 새집의 시작을 더 깨끗하고 편안하게
- 청소 비용, 먼저 확인하세요.
- 추가 비용도 먼저 안내합니다.
- 보이지 않는 곳까지 확인하는 청소
- 작업 완료 후 고객이 직접 확인합니다.

## 6. 주요 섹션별 역할

### Hero
첫 화면에서 다음을 직관적으로 이해시킨다.
- 입주·이사청소 업체
- 깨끗함
- 신뢰감
- 가격 투명성
- 견적 요청

추천 H1:
입주 전 마지막 걱정까지
깨끗하게 정리하세요

추천 Sub:
입주·이사 전 공간을 꼼꼼하게 청소하고,
평수별 기본 가격과 추가비 조건까지 먼저 안내합니다.

Primary CTA:
우리 집 기본 비용 확인하기

### 가격
제목:
청소 비용, 먼저 확인하세요.

목적:
고객이 가격을 먼저 확인하고 견적 요청 여부를 판단하게 한다.

### 추가 비용
제목:
추가 비용도 먼저 안내합니다.

핵심:
추가 비용이 필요한 경우 작업 전에 사진 확인 또는 상담을 통해 먼저 안내합니다.

### 청소 방식
제목:
보이지 않는 곳까지 확인하는 청소

핵심 포인트:
- 전문 장비
- 친환경 세제
- 공간별 체계적인 청소
- 고객 검수

### 신뢰
핵심 수치:
누적 1,200건+의 입주·이사청소 경험

### 후기
제목:
직접 이용한 고객의 이야기

### 검수/보완
제목:
청소가 끝난 뒤에도 직접 확인하세요.

### 지역
제목:
서울·경기 지역을 중심으로 방문합니다.

CTA:
우리 지역 예약 가능 여부 확인하기

### Final CTA
추천 카피:
입주 날짜가 정해졌다면
지금 필요한 건 견적 확인입니다.

Primary CTA:
평수와 날짜 보내고 견적 받기

## 8. 정보 사용 원칙
- 01_FACTS.md의 사실은 임의 변경 금지
- 가격·정책·실적·서비스 범위를 새로 만들지 않음
- 실제 자료가 없는 영역은 디자인 시안 단계에서는 시안용 가상 자산 사용 가능
- 실제 공개 전 실제 자료로 교체
